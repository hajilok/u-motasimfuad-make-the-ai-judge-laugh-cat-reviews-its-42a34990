# Make the AI Judge Laugh: Cat Reviews Its Human

Entry for the [make.fun](https://make.fun/r/41fw6r6c) competition **Make the AI Judge Laugh: Cat Reviews Its Human** (`u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990`).

## Usage

```bash
node main.ts
```

Writes a deterministic, single-line, sub-200-character UTF-8 one-star cat review to `/output/entry.txt` (or `<dir>/entry.txt` if an output directory argument is passed for local testing).
